# مشوار

تطبيق طلب عربيات (زي أوبر) بالعربي بالكامل. ألوانه أصفر التاكسي (#FFC21A) مع أسود فحمي وأبيض، وفيه وضع غامق. ورقته الزجاجية المضبّبة فوق الخريطة على نفس فكرة التصميمات المرجعية.

الخط IBM Plex Sans Arabic، والأيقونات من [Phosphor Icons](https://phosphoricons.com) (رخصة MIT) بوزن duotone من غير إطارات (الخط أسود والملء أصفر)، والعربيات متولّدة 3D بألوان عربيات الكباتن.

الورقة اللي تحت الخريطة بتتسحب في كل الشاشات: لتحت (تشوف الخريطة أكتر)، للنص، أو لفوق لحد ما تملا الشاشة. ولما تكون مفتوحة لآخرها، الضغط على الخريطة فوق بيرجّعها للنص.

دي **نسخة تجريبية**: الكباتن والعروض وحركة العربية على الخريطة كلها محاكاة، عشان تقدر تجرب المشوار كله من الأول للآخر.

## التشغيل

مفيش أي حاجة محتاجة تتسطب. افتح `index.html` في المتصفح (أحسن حاجة من الموبايل أو بوضع الموبايل في أدوات المطور).

علشان تعمل ملف واحد تبعته لأي حد:

```bash
python3 build.py          # بيطلّع dist/mishwar.html
```

## المشوار من الأول للآخر

1. **الرئيسية**: خريطة فيها موقعك والعربيات اللي حواليك، وكارت "اطلب عربية".
2. **خطط لمشوارك**: اكتب أو اختار نقطة الركوب والوجهة، أو حددها بالدبوس على الخريطة.
3. **تفاصيل المشوار**: المسار على الخريطة، المسافة والوقت، والسعر المقترح (تقدر تزوّده أو تقلّله)، وبعدين "اطلب الآن".
4. **العروض**: الكباتن بيبعتوا عروضهم واحد ورا التاني (الاسم، التقييم، العربية، اللوحة، السعر، ووقت الوصول). كل عرض متاح ٣٠ ثانية.
5. **الرحلة**: الكابتن جاي ← وصل ← في الطريق ← وصلت. فيها رمز المشوار، واتصال، ورسائل، ومشاركة الرحلة، وزرار الأمان. زرار "تسريع (للتجربة)" بيخلص المرحلة الحالية على طول.
6. **التقييم**: نجوم، ملاحظات سريعة، إكرامية، وتعليق. المشوار بيتسجل في "مشاويري السابقة".
7. **حسابي**: المشاوير السابقة وتفاصيلها، الأماكن المحفوظة، طرق الدفع، الإعدادات (الاسم، الوضع الليلي، الإشعارات...)، المساعدة، وعن التطبيق.

## الملفات

| الملف | فيه إيه |
|---|---|
| `index.html` | هيكل الشاشة |
| `css/app.css` | التصميم كله (الألوان في أول الملف) |
| `js/app.js` | الشاشات والتنقل بينها |
| `js/map.js` | خريطة المدينة المرسومة بالكود، والكاميرا، والعلامات، والمسارات |
| `js/mock-api.js` | **السيرفر التجريبي**: الأسعار، العروض، وحركة الكابتن |
| `js/data.js` | الأماكن والمناطق |
| `js/icons.js` | دوال الأيقونات والعربيات والصور الشخصية ولوحة العربية |
| `js/icon-set.js` | أيقونات Phosphor المستخدمة (مولّد بـ `tools/make_icons.py`) |
| `js/assets.js` | صور العربيات جوه الكود (مولّد بـ `tools/make_assets.py`) |
| `assets/img/` | نفس صور العربيات كملفات WebP |
| `tools/car-render.html` + `tools/car-render.js` | بيرسموا العربيات 3D بـ three.js (أي لون، من الجنب ومن فوق) |
| `tools/make_assets.py` | بيصغّر صور العربيات ويكتب `js/assets.js` |

## الربط بحاجة حقيقية (الخطوة الجاية)

- **السيرفر**: نكتب ملف بدل `mock-api.js` بنفس الواجهة (`estimate` و`requestRide` و`accept` و`cancel`) وبنفس الأحداث (`offer` و`offer-expired` و`phase` و`update` و`completed`)، يكلم API وWebSocket حقيقيين. باقي التطبيق مش هيتغير.
- **الخرائط**: نبدل `map.js` بـ Google Maps أو Mapbox، بنفس الدوال (`fit` و`flyTo` و`setMarker` و`drawRoute`).
- **تطبيق الكباتن**: تطبيق تاني يستقبل الطلبات ويبعت العروض والموقع.
- **الحسابات والدفع**: تسجيل دخول برقم الموبايل، ودفع إلكتروني.
- **متجر التطبيقات**: نغلّف التطبيق بـ Capacitor عشان يتنزل على أندرويد وآيفون.
